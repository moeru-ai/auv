# Proposed Update for Issue #211 Command Tree

This document contains the proposed update to issue #211's (`Roadmap of AUV Invoke: cross-platform support`) command tree, generated for **Brief 1** of the Windows `scroll_until` parity iteration chain.

Per Brief 1 instructions, this proposal reconciles the issue tree with `support.rs` declarations as of current `main` (commit `c24c2e7e`, including #339, #340, #341, and #342):
- macOS and Linux cells and descriptions are preserved without modification.
- Meta-sections (Status rules, User Stories, Testing Decisions) remain untouched.
- `input.scroll` and `input.scrollUntil` rows are explicitly incorporated, with Windows cells honestly marked as `"source present, live evidence pending"` pending Briefs 2–6.
- Windows implementations landed in recent PRs (#341 paste text, #342 media control SMTC) are updated to match their typed declarations in `support.rs`.

All macOS and Linux columns and meta-sections remain untouched. Brief 2 can now proceed to measure real-world WGC settle timing on Windows using QQ Music and an editor/browser surface, providing the first live latency evidence required to promote `input.scroll` and `input.scrollUntil` to validated status.
