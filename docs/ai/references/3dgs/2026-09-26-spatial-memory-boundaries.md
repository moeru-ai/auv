# ADR：结构化空间记忆的架构边界（2026-09-26）

> 状态：Accepted。记录 `spatial_memory_store` / `spatial_memory_query` 的已知局限，
> 防止后人误将"坐标便签本"当作"完整空间记忆系统"。

## 背景

3DGS-as-memory 已证伪并暂停（2026-09-25 closeout）。Step 2 用结构化 landmark
存储 + 确定性几何查询替代了它。测试通过，但以下 6 条是架构级局限，
不是实现 bug，修 bug 修不掉。

## 边界 1：无遮挡推理

`spatial_memory_query` 只做视锥裁剪。视场内的点一定算出屏幕坐标，
无法判断前方是否有遮挡。当前策略：遮挡未知时返回 `Unknown`，绝不猜 `Occluded`。

**后果**：下游不能把 `Visible` 理解为"可交互"，只能理解为"在视场内"。
真遮挡需要占用栅格（occupancy grid）或深度缓冲，那是独立的大工程。

## 边界 2：ingest 依赖 Tier 3 telemetry

`spatial_memory_ingest` 从 `frame.telemetry.raycast_hit` 拿绝对世界坐标，
这是 Minecraft Mod 探针，不是黑盒 Tier 0 信号。脱离该 Mod 即失效。

**但 API 边界是干净的**：`SpatialMemoryQuery`/`SpatialMemoryAnswer`
不依赖引擎真值。可移植的是记忆模块，**不可移植的是 ingest**。
任何新平台（闭源游戏/桌面应用）必须重写 ingest，用该平台的感知手段
（视觉 SLAM / 深度估计 / 2D 检测+反投影）填充 landmark。

## 边界 3：针孔感知

raycast 只有准星中心单像素。M2 会话 3 帧只产出 1 个 landmark，
v03 因视角上抬直接 `observations_skipped`。全帧 99.999% 像素的空间信息被丢弃。

**后果**：靠准星建图的带宽不可实用。全图建图需要 2D 检测 + 深度，
见边界 4。

## 边界 4：2D↔3D 双向断裂

- 3D→2D：已实现（投影）。
- 2D→3D：缺失。VLM 在屏幕上检测到目标后，没有深度就无法反投影存入 store。
- Landmark 的 label 是机械生成的 `block_x_y_z`，无视觉特征描述子，
  上层无法按语义（"箱子在哪"）查询。

**后果**：这是当前架构最核心的缺口。补上需要：2D 检测器（YOLO-World，Step 4）
+ 单目/多目深度估计 + 特征嵌入。缺任何一块，VLM 的发现都存不进记忆。

## 边界 5：无动态更新

`upsert_landmark` 只增不减，置信度只升不降。方块被挖掉后 landmark
永久残留且置信度 0.99。无负观测（ray-clearing）、无贝叶斯衰减、无老化删除。

**后果**：当前 store 只适用于静态场景假设。动态世界需要占用概率更新，
参考 OctoMap 的 hit/miss 计数机制。

## 边界 6：实现层硬编码

- `spatial_memory_query` 的合成投影矩阵写死垂直 FOV=70°，
  Minecraft 实际 FOV 可调（70–110°+动态变化），偏差可达数十像素。
- 方块位置取体素中心（+0.5），但交互面向的是表面（BlockFace），
  近距离有数像素到数十像素视差。
- 去重半径 0.6m 是常量；一旦位姿有漂移（非靶场场景），该阈值会雪崩。
  应参数化。

## 定位

| | 3DGS 方案 | 当前结构化方案 | 完整记忆需要的 |
|---|---|---|---|
| 外观推断 | 理论有（小样本过拟合） | 无 | 稀疏视角 patch/特征检索 |
| 遮挡推理 | Alpha 排序天然支持 | 无（边界 1） | 占用栅格/深度缓冲 |
| 真值来源 | 试图纯 RGB | Tier 3 作弊（边界 2） | 视觉 SLAM/深度估计/三角化 |
| 感知带宽 | 全图 | 准星单点（边界 3） | 2D 检测+深度反投影 |
| 语义接地 | 无 | 无（边界 4） | 检测器+特征嵌入 |
| 动态更新 | 梯度（慢） | 无（边界 5） | 贝叶斯占用更新 |

**一句话**：当前实现是"在特定 telemetry 探针辅助下的离散坐标锚点本"，
不是自主空间记忆系统。它的价值是确定性核心（存储+查询 plumbing），
感知与动态是后续步骤的任务。

## 对路线图的影响

- Step 4（YOLO-World）：解决边界 4 的前半（2D 检测），还需深度估计补后半。
- 未来步骤：占用栅格（边界 1+5）、ingest 可移植层（边界 2）、全图建图（边界 3）。
