# ADR：结构化空间记忆的架构边界（2026-09-26）

> 状态：Accepted。记录 `spatial_memory_store` / `spatial_memory_query` 的已知局限，
> 防止后人误将"坐标便签本"当作"完整空间记忆系统"。

## 背景

3DGS-as-memory 已证伪并暂停（2026-09-25 closeout）。Step 2 用结构化 landmark
存储 + 确定性几何查询替代了它。测试通过，但以下 6 条是架构级局限，
不是实现 bug，修 bug 修不掉。

## 边界 1：无遮挡推理

`spatial_memory_query` 只做视锥裁剪。视场内的点一定算出屏幕坐标，
无法判断前方是否有遮挡。当前策略：遮挡未知时返回 `Unknown`，绝不猜 `Occluded`。

**后果**：下游不能把 `Visible` 理解为"可交互"，只能理解为"在视场内"。
真遮挡需要占用栅格（occupancy grid）或深度缓冲，那是独立的大工程。

## 边界 2：ingest 依赖 Tier 3 telemetry

`spatial_memory_ingest` 从 `frame.telemetry.raycast_hit` 拿绝对世界坐标，
这是 Minecraft Mod 探针，不是黑盒 Tier 0 信号。脱离该 Mod 即失效。

**但 API 边界是干净的**：`SpatialMemoryQuery`/`SpatialMemoryAnswer`
不依赖引擎真值。可移植的是记忆模块，**不可移植的是 ingest**。
任何新平台（闭源游戏/桌面应用）必须重写 ingest，用该平台的感知手段
（视觉 SLAM / 深度估计 / 2D 检测+反投影）填充 landmark。

## 边界 3：针孔感知（Step 4 部分解除）

- **Step 2 状态**：raycast 只有准星中心单像素。全帧 99.999% 像素的空间信息被丢弃。
- **Step 4 进展（2026-09-26）**：引入全图 2D 检测器（`YoloWorldDetector`）+ 稠密单目深度估计（`DepthEstimator`，支持 MiDaS v2.1 Small 与 Depth Anything V2），实现视场内全图目标自动发现与提取。
- **剩余局限**：模型开销（100-200ms）不宜逐帧运行，采用关键帧/步长触发策略；小目标与遮挡目标仍受分辨率与检测灵敏度限制。

## 边界 4：2D↔3D 双向断裂（Step 4 基本打通）

- 3D→2D：已实现（确定性投影 `spatial_memory_query`）。
- 2D→3D（Step 4 已实现）：
  - 框中心点取预测深度图的视差值。
  - 通过准星 raycast 真实深度线性校准单目尺度因子（$\text{scale} = d_{\text{true}} / d_{\text{pred}}$）。
  - 基于 Minecraft 实际 FOV 与相机外参（平移、偏航 yaw、俯仰 pitch）实现严格逆矩阵反投影（`back_project`），恢复世界坐标系 3D 点。
  - 几何误差验证通过（$< 2.0\text{m}$，实测中心射线与 raycast 绝对真值重合）。
- 语义接地（Step 4 已实现）：
  - YOLO-World 开放词表支持预置 Minecraft 类别（`chest`, `furnace`, `crafting_table`, `door`, `bed`, `torch`, `ore`, `player`, `zombie`, `skeleton`）。
  - 预计算 CLIP 文本嵌入内联至二进制文件，实现零额外 Python/CLIP 运行时开销。
  - 视觉感知 Landmark 携带语义标签（如 `"chest (0.87)"`）经 `VisualPerceptionIngest` 存入 `SpatialMemoryStore`。
  - 支持与准星真值异构多源融合（`Confirmed` 优先策略，保留准星厘米级几何真值同时注入视觉语义标签）。
- **剩余局限**：单目深度仍需绝对尺度锚点校准；极低纹理像素表面深度估计精度弱于现实世界几何结构。

## 边界 5：无动态更新（Step 2 加固已解决）

- **Step 2 加固进展**：已实现 Landmark 完整生命周期管理：
  - 多次观测置信度提升（最多 0.99，观测计数自增）。
  - 负观测衰减（视场内未命中则惩罚置信度）。
  - 随步数/时间半衰期老化衰减（`decay_all`）。
  - 淘汰清理（过期标记、低置信度修剪 `evict_stale`）。
- **剩余局限**：尚未引入细粒度 3D 占用栅格（Occupancy Grid / OctoMap），目前以离散 Landmark 为单位进行概率更新。

## 边界 6：实现层硬编码（Step 2 加固已解决）

- **Step 2 加固进展**：
  - 投影矩阵与反投影支持可配置垂直 FOV（默认 70°，可按游戏设置动态传入）。
  - 去重与聚类半径参数化（默认 0.6m，可外部配置）。
  - 生命周期老化与置信度阈值全部开放为可配置策略。

## 定位

| | 3DGS 方案 | Step 2 结构化方案 | Step 4 视觉感知方案 | 完整记忆需要的 |
|---|---|---|---|---|
| 外观推断 | 理论有（小样本过拟合） | 无 | 语义标签 + 2D BBox | 稀疏视角 patch/特征检索 |
| 遮挡推理 | Alpha 排序天然支持 | 无（边界 1） | 深度图前向遮挡判定（初级） | 3D 占用栅格/深度缓冲 |
| 真值来源 | 试图纯 RGB | Tier 3 作弊（边界 2） | 深度模型 + 标定锚点反投影 | 视觉 SLAM/多目立体/尺度恢复 |
| 感知带宽 | 全图 | 准星单点（边界 3） | **全图 2D 检测 + 深度（边界 3 已解）** | 连续全图稠密建图 |
| 语义接地 | 无 | 无（边界 4） | **开放词表 YOLO-World（边界 4 已解）** | 开放词表检测 + 3D 实例分割 |
| 动态更新 | 梯度（慢） | 无（边界 5） | **置信度衰减+负观测+清理（边界 5 已解）** | 贝叶斯占用栅格更新 |

**一句话**：系统已从"准星单点坐标便签本"升级为"具备全图 2D 开放词表语义检测、单目深度反投影定位与生命周期管理的结构化空间记忆核心"。

## 对路线图的影响

- Step 2 生产级加固：解决了边界 5（生命周期/动态更新）和边界 6（硬编码）。
- Step 4 视觉感知管线：解决了边界 3（针孔感知）和边界 4（2D↔3D 断裂与语义接地）。
- 下一步任务：
  - 边界 1：基于深度图或视锥栅格的遮挡推理（避免透过实心墙壁观测目标）。
  - 边界 2：脱离 Mod 探针的黑盒无锚点尺度初始化（如通过运动视差/视觉 SLAM 替代绝对深度锚点）。
